# Jom Padankan! Haiwan dan Makanannya

BBM digital interaktif untuk Aiman (9 tahun) – memadankan tiga haiwan dengan makanan yang betul.

## Ciri-ciri
- Halaman Mula, Arahan (dengan audio), Aktiviti Seret & Lepas
- Maklum balas positif (Tahniah!) dan galakan (Cuba Lagi!)
- Arahan berbentuk audio (Bahasa Melayu)
- Boleh digunakan pada komputer, tablet dan telefon pintar

## Cara guna
Buka `index.html` dalam pelayar.

## Terbitkan di GitHub Pages
1. Muat naik semua fail ke repositori GitHub.
2. Settings → Pages → Branch: `main` / folder `/ (root)` → Save.
3. Pautan akan muncul dalam beberapa minit.
